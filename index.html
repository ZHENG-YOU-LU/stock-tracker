＋ 新增自選股

第一次使用要建立一組權杖，讓這個網頁能叫雲端執行動作。權杖只存在這支手機的瀏覽器，不會上傳。

  1. 用 Safari 開 建立權杖頁，名稱隨意
  2. Repository access 選 Only select repositories，只勾 stock-tracker
  3. Permissions → Repository permissions：Actions 設 Read and write；Contents 設 Read-only
  4. 按 Generate token，複製後貼到下面

權杖只能操作這個 repo 的工作流程與讀取內容，不要分享給別人。權杖有到期日，到期後重新建立即可。

只支援上市股票。沒填成本價就以最近收盤價為起點；停損 −7%、目標 +15%，與規則推薦相同。加入約需 30～90 秒。自選股不會計入「規則表現」的統計。

規則表現

報酬 = 目前（或結案時）收盤價相對推薦價；大盤 = 流動性足夠上市股票的等權重平均。超額報酬大於 0，才代表贏過大盤。

同一檔股票的推薦彼此不獨立，且推薦日價格是當日收盤價，實際無法剛好買在這個價位，真實績效通常會更差。

推薦規則（每個交易日收盤後自動執行）

評分達 分才推薦：站上月均價且未過熱（30）、當日溫和上漲（20）、量能放大（30）、成交值前 100 名（20）。停損 −7%、目標 +15%、最長追蹤 個交易日。

這是量化規則篩選，不是投資建議，也不保證獲利。台股慣例：紅色上漲、綠色下跌。

加到手機主畫面

iPhone：用 Safari 開這個網址，點下方的分享按鈕，選「加入主畫面」。之後就能像 App 一樣全螢幕開啟。Android：Chrome 右上選單 →「加到主畫面」。

兩個更新按鈕差在哪

重新整理：只是重新讀取網頁上已有的資料。⚡ 立即更新：叫雲端現在跑一次，盤中會抓最新報價（證交所為主，失敗時用 Yahoo 補，可能延遲約 20 分鐘），約需 30～60 秒。需要先完成權杖設定。

收盤價每個交易日只更新一次；即時價是盤中的報價，只在你按下立即更新時才會刷新。

名詞

  • 超額報酬：這檔的報酬減去同期大盤報酬，大於 0 才算贏過大盤。
  • 進度條：左端是停損價、右端是目標價，圓點是最新收盤價，細線是推薦價。
  • 快觸及停損：最新價距離停損價不到 3%。
